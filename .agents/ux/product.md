# 产品地图（项目层 · Byline）

> 日常 UI 任务先读这里，再进 lobe-design stage。体验对标 Ghost Admin：新页面、重做和打磨先读 `ghost-design-guide.md`（目标体验与差距表），再读 `lobe-design-rules.md`（已做的取舍与纠正）。产品事实以本文件为准；判断标准以 skill 为准。界面在 `apps/admin`（React 19 SPA），API 在 `apps/server`。范围以 `docs/superpowers/specs/2026-10-22-byline-design.md` 为准。

## 0 谁在用、为什么来

Byline 是多作者、只提供 API 的内容系统。后台给站点的编辑和运营使用：写文章、管发布、看产物、管用户和站点设置。邀请制，使用频率高，桌面浏览器为主。窄屏只保证导航和列表可用。

**来意**：打开一篇稿 → 改完发布 → 核对译文 / 摘要 / 语音等产物 → 处理失败任务。偶发：邀请用户、改设置、清孤立文件、看 webhook。

## 1 主路径与关键流程

- **写作发布**：总览或文章列表 → 写作页 → 保存草稿 → 发布（可带 AI 任务）。
- **改已发布内容**：已发布列表 → 写作页 → 再编辑或看草稿版本。
- **核对产物**：产物分组 → 概览 → 译文 / 摘要 / 精读 / 朗读 → 失败则重试。
- **管人和站点**：用户列表 → 邀请或停用；设置里改站点、账号、AI 供应商。
- **文件**：文件列表 → 上传或清理孤立文件。

## 2 页面地图

| 侧栏分组 | 页面 | 原型 | 主任务 |
| --- | --- | --- | --- |
| （顶栏） | 总览 | P-01 | 看运行状态，决定先去写还是先处理失败任务 |
| 文章 | 草稿、已发布、写文章、分类 | P-02 / P-03 | 找到一篇稿，决定发、改或归档 |
| 产物 | 概览、翻译、摘要、精读、朗读、任务、翻译词表 | P-02 / P-07 | 看译文、摘要、精读、朗读是否齐，决定补生成或重试 |
| 资源 | 文件、孤立文件 | P-02 | 找到资源，决定保留或清理 |
| 系统 | 用户、设置、Webhook | P-02 / P-05 | 邀请或停用账号；改站点、AI 与出站端点 |

公开页（登录、邀请、初始化、重置密码）不进侧栏。

## 3 核心对象与动作

| 对象 | 生命周期 | 关键写操作 | 风险 |
| --- | --- | --- | --- |
| 文章 / 草稿 | 草稿 → 发布；修订树保留 | 保存、发布、删除草稿 | 发布对外可见；删除草稿不可撤回 |
| 分类 | 创建 → 改名 → 删除 | 创建、改名、删除 | 删除影响归类，文章还在 |
| 用户 | 邀请 → 启用 ↔ 停用 | 邀请、停用 | 停用保留文章和署名 |
| 产物 | 排队 → 成功 / 失败；导入译文可锁定 | 生成、重试、跳过锁定语言 | 重生成会覆盖未锁定译文 |
| 文件 | 上传 → 引用或孤立 → 清理 | 上传、删除孤立文件 | 删除不可撤回 |
| Webhook | 配置 → 投递成功 / 失败 | 改端点、重放 | 重放会再次打到对方 |
| 设置 | 保存即生效 | 改站点、AI 供应商、密钥 | 密钥和供应商影响后续生成 |

## 4 术语

| 用这个词 | 说明 |
| --- | --- |
| 总览 | 侧栏第一项，看全站要处理的事 |
| 已发布 | 侧栏和列表页标题，指已经发出的文章 |
| 文章 | 一篇 post。侧栏里已发布的那一项叫「已发布」 |
| 产物 | 译文、摘要、精读、朗读。侧栏分组就叫「产物」 |
| 草稿 | 未发布或自动保存的版本 |
| 署名 | 作者顺序，就是 byline |
| 锁定 | 导入的译文，发布时默认不覆盖 |
| 孤立文件 | 没有被文章引用的文件 |

## lobe-design 适用性与文案（05-init Round 1）

平台：web

- 产品类型：内容管理后台（编辑 / 运营，高频，桌面为主）
- 用户：受邀作者与站点管理员。权限位已预留，v1 不按位拦截。
- copy-profile: admin
- 人称：无主语。按钮写动作（「发布」「删除草稿」）。中英两套文案在 `apps/admin` 的 i18n 资源里，默认语言 zh-CN。

| 适用性 | 规则 |
| --- | --- |
| 强调 | P-01 总览、P-02 列表、P-03 详情、P-05 设置、P-07 状态监控（任务与产物） |
| 强调 | C-07 控制台套件（`ConsoleShell` / `ConsoleNav`），原子层用 `@lobehub/ui` |
| 不适用 | 营销页、落地页、消费级聊天的原型和文案语气 |
| 不适用 | 触控优先；个人博客模块（评论、笔记、订阅、说说等）不在产品范围 |
